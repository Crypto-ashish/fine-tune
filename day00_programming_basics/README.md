# Day 0 — Programming Basics

**Start here if you have never programmed.** 13 short lessons covering only the Python used in the fine-tuning code. No GPU needed. About 2–3 hours.

## Files

| File | What it is |
|---|---|
| `day00_programming_basics.ipynb` | The lessons as a Colab notebook. Outputs are already saved, so you can read them before running. Each lesson ends with an empty cell for your own experiments. |
| `Day00_Programming_Basics.docx` | The same lessons as a document to read, plus a cheat sheet and the Day 1 bridge table. |

## Lessons

1. What a program is, and `print()`
2. Variables
3. Types: text, whole numbers, decimals, True/False
4. Maths and f-strings
5. Lists
6. Dictionaries
7. `if` / `else`
8. `for` loops
9. Functions
10. Libraries, objects and the dot
11. Slicing
12. Reading errors
13. Mini project: a toy tokenizer

The final section, **Bridge**, maps every important line of Day 1's code to the lesson that explains it.

## How to run

1. Go to https://colab.research.google.com → **Upload** → choose `day00_programming_basics.ipynb`.
2. Click inside a grey code cell and press **Shift + Enter**. Run the cells in order, from top to bottom.
3. Three cells in Lesson 12 are meant to show errors. When Colab stops at one of them, read the error, then run the cells after it one at a time.

All example outputs come from a real run (Python 3.13).
