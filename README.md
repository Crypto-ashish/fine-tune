# Fine-Tune: Practical LLM Fine-Tuning in 30 Days

Code-first lessons for learning to fine-tune open-source language models with Hugging Face, PyTorch, PEFT, LoRA and QLoRA.

Each day has its own folder with a runnable notebook or script, a DOCX tutorial and a README.

| Day | Folder | Topic |
|---|---|---|
| 0 | [`day00_programming_basics`](day00_programming_basics/) | Programming basics for complete beginners — **start here** |
| 0B | [`day00b_how_fine_tuning_works`](day00b_how_fine_tuning_works/) | How fine-tuning works, why it's done, and using it for content creation |
| 0C | [`day00c_coding_practice`](day00c_coding_practice/) | Coding practice: files, JSONL datasets, cleaning, splitting, configs, padding, a loop that learns |
| 1 | [`day01_first_model`](day01_first_model/) | Run your first AI model (Qwen2.5-0.5B-Instruct) |

## Quick start
Open a day's `.ipynb` in [Google Colab](https://colab.research.google.com), set **Runtime → T4 GPU**, and run cells top to bottom.
